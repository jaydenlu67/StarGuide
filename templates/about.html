Understanding Our Stack

This page details the core technologies driving your web application. We prioritize **server-side rendering** using Python, keeping the front-end simple and styled with Bootstrap.

Flask (Python)
The Web Framework

Flask handles all routing, request processing, and database interaction. It's lightweight and perfect for building with Python.

  • ✔️ Intermediate Python skills applied here.
  • ✔️ Manages application context and configuration.
SQLite
The Database Backend

A file-based, relational database that is excellent for development and small applications. No separate server process is needed.

  • ✔️ Simple setup with no configuration.
  • ✔️ Data persistence for your application.
Bootstrap 5 & Jinja2
The Front-end & Templating

Bootstrap provides professional, mobile-friendly styling. Jinja2 allows Python to insert dynamic data into this HTML.

  • ✔️ No custom JavaScript required.
  • ✔️ Responsive design built-in.
